\begin{center}
    { \LARGE \textbf{Abstract}}
\end{center}
\vspace{1.5cm}
{\large
Large Language Models (LLMs) are commonly accessed through hosted APIs, where repeated requests can add latency and provider cost. VeriGate is an asynchronous FastAPI gateway that centralises API-key authentication, request limits, provider routing, streaming, cache management and observability. Its cache has two modes: exact UTF-8 prompt matching is the default, while approximate semantic matching is an explicit opt-in. In semantic mode, VeriGate embeds a query with a sentence-transformer model, retrieves a tenant-scoped nearest neighbour, computes an adaptive similarity threshold from query features and neighbourhood density, and applies structural verification before reusing the stored answer. An optional bidirectional natural-language-inference (NLI) cross-encoder adds a further statistical check; keyword-based volatility rules bypass selected time-sensitive queries. The system also includes an optional heuristic model cascade, circuit breakers, Redis-backed rate limiting, per-key daily admission limits, and Prometheus metrics with an operator dashboard. On the checked-in 30-pair curated semantic benchmark, adaptive thresholding plus Tier-1 verification accepted 5 of 15 positive pairs and 0 of 15 negative pairs; this is a limited dataset result, not a universal correctness guarantee. The 40-query cascade experiment reports a simulated 46.7\% cost reduction at 100\% retention of labelled hard queries under an illustrative 15:1 strong-to-cheap cost ratio. Local audit evidence records 50 passing tests and 4 live-Redis tests skipped; release readiness still depends on validation of the exact revision and deployment environment. The report distinguishes measured observations, simulated estimates, and unverified production requirements.
}
