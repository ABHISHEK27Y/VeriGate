B.Tech Major Project — LLM Gateway

A semantic cache that verifies every hit before it answers.

VeriGate reuses answers for reworded questions to cut LLM cost and latency — but a two-tier verifier rejects look-alike matches, so a query like “capital of Australia” never receives the cached answer for “capital of Austria.”

01

The contribution

A

Adaptive threshold

Match strictness is computed per query from entities, numbers, length and neighbourhood density — not one global constant.

B

Self-verifier

Two tiers — structural checks (numbers, negation, entities) then NLI equivalence — reject false hits similarity alone would accept.

C

Staleness detection

Time-sensitive queries are detected and never cached, so a cached answer can’t go stale.
