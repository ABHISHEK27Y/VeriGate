# Dataset attribution and changes

The `workload.csv` and `provider_answers.json` files are derived from
[NQ-Open train](https://github.com/google-research-datasets/natural-questions/blob/master/nq_open/README.md)
under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
VeriGate selected song-writer source questions, authored three paraphrase
templates and one song-title swap per family, changed punctuation, and shuffled
the order. The source file hash and source-line references are in this run.
These derived data files are shared under CC BY-SA 3.0.
